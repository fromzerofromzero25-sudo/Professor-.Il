# Professor AI — المشروع الموحّد

هذه النسخة تجمع واجهة الموقع العربية/الإنجليزية مع اتصال خادمي بـ Gemini.

## الملفات
- `index.html`: واجهة الموقع.
- `netlify/functions/chat.mjs`: نقطة الاتصال الآمنة بخدمة Gemini.
- `netlify.toml`: إعدادات Netlify.

## إعداد المفتاح (لا تضعه داخل HTML)
1. افتح إعدادات موقعك في Netlify.
2. اذهب إلى **Environment variables**.
3. أضف متغيراً اسمه `GEMINI_API_KEY` وضع قيمة المفتاح في خانة القيمة.
4. أعد نشر الموقع حتى تُطبّق الإعدادات.
5. افتح الموقع واختبر سؤالاً برمجياً.

لا ترسل مفتاح API لأي شخص، ولا تضعه في ملفات الموقع أو في مستودع عام.

## ملاحظات
- الاتصال الفعلي يحتاج استضافة تدعم Netlify Functions ومفتاح Gemini صالحاً.
- قد تنطبق حدود استخدام أو رسوم وفق إعدادات حساب Google AI Studio؛ تحقق منها قبل الاستخدام.
- لم يتم نشر الموقع أو اختباره بمفتاح حقيقي ضمن هذه الحزمة.
